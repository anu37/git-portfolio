
# Anu Abraham · GitHub Pages CV

A single-page, responsive resume site inspired by the Wix "CV Responsive" template.

## Deploy to GitHub Pages

1. Create a new public repo named `anu37.github.io` (or any repo, then enable Pages).
2. Put `index.html` at the root of the repo.
3. (Optional) Add your resume PDF as `Anu_Abraham_CV.pdf` and update the link in the **Download CV** section.
4. Commit & push. In repo settings → **Pages**, set Source to `main`/`root` if needed.

That's it 🚀
